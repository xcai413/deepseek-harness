# Persona Appearance Assets v0.1

This directory contains visual identity assets for Persona Packs.

## Current scope

- avatar image
- background image
- accent color
- overlay effect
- transition preset

## JARVIS example

`jarvis/theme.yaml` defines the first appearance contract:

- HUD style overlay
- cyan accent
- slow motion background effect
- system boot transition
